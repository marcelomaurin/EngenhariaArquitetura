# EngenhariaArquitetura

Software para Engenharia e Arquitetura.

Plataforma de aplicações independentes em Lazarus/Free Pascal que funcionam como uma linha de produção de projetos de edificações:

1. **Planejador** — tarefas, cronograma e coordenação das etapas.
2. **CAD Arquitetônico 2D** — plantas baixas com objetos inteligentes (paredes, portas, janelas, ambientes).
3. **Maquete 3D** — reconstrução da edificação a partir das plantas, editor de objetos e gerador de texturas.
4. **Criador de Cenas Realistas** — câmeras, iluminação, animação e renderização fotorrealista.
5. **Elétrica 3D** — projeto das instalações elétricas sobre a maquete.
6. **SimuEletrica** — simulação elétrica, falhas, proteções e análise térmica.
